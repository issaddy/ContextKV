## 运行合同

完整dev为22会话/159轮：ClapNQ 6/47、FiQA 5/32、Govt 6/39、Cloud 5/41。8B按P2使用自身已提交的完整QA，每轮REBUILD；所有159轮成功后冻结实际输入，32B逐轮重放这些输入。32B的新答案不写回后续历史，因此它不是32B自有历史闭环。官方top5是固定输入协议，不是oracle，不保证来源充分。

两模型采用Q0、非思考模板、temperature0.7/top_p0.8/top_k20/min_p0、输出cap1024、正常EOS、c1、server seed42和固定会话顺序。不声称逐请求确定性；length答案保留并进入分母，不重试或提高预算。模型分别串行运行，未使用旧cost/length标定、研究planner或host/session缓存；原生Radix前缀缓存仍可使用。

执行源码为`a6b5711d1c82ac0fae8f8c26d8b3d6efd2ba82c1`，远端325个tracked Git blobs在启动前核验。固定stock SGLang为`3f36fc08331f64cd63c4fbbdf39cc402f38bb38b`，未应用研究补丁；BF16权重/KV、TP/DP/PP1、FA3、page64、context32768、GPU pool32768、chunked prefill8192、无HiCache/session radix。独立运行器保留每次真实HTTP、终态、完整input/output IDs和前序QA。此批身份是`generator_capability_reference`，不是正式B0/B6。

本地权重来源只确认实际config、分片库存/字节及tokenizer/template，未确认HF revision或权重内容摘要，保留`local_snapshot_metadata`与`weight_content_verified=false`。不能把本地身份标签写成已验证上游commit。后续主工程[显式模型接入](../guides/model_scope.md)是独立的`a87638a`实现，不追改本批源码或借本批stock结果宣称研究补丁已通过GPU验证。

### 反复出现的根因

- **对象、角色与条件未随事实保留。** Cloud中同名SDK、CLI与plug-in、文档与附件限制仍会混用；Govt中一般心脏健康页的减重建议被套到儿童、建议被写成法律must。ClapNQ中8B将“理想情况下近亲捐献”写成必需近亲，将两人250磅/日换成每工人250倍；32B又将供棉主体Confederacy写成Britain。数字或句子摘录准确，仍可能回答了错误对象或改变分母。
- **时间、事件类型与材料立场被压平。** 8B把HIV初次传播改成初次reported；同源2015全国合法的材料被它总结为同性婚姻当前仍非全国合法。32B在Govt把101mm统计嫁接到另一时间段，FiQA将历史经济预测或论坛作者意见升级为当前确定结论。相同实体/关键词不足以绑定事件和有效时间。
- **引用身份与支持关系分离。** 当前E_ID真实也可能不支持该数字、日期或税收结论；历史已见、当前不可见的ID不是自动虚构，更不能把历史助手转述当本轮外部正文。FiQA还保留一个真正未见的近似ID转录错误，并与其可由正确原文支持的论断分开。Cloud中32B在某轮去掉无据VA命令，后一轮仍可能从它收到的**8B历史**复制该命令；这不是32B自身前答传播。
- **来源缺口或冲突被补成答案。** “没有找到限制”被推成无硬上限，“没有该项法规材料”被推成不存在法规；流感接种名单从水痘/一般疫苗资料拼出。材料本身也会冲突，如Friends第三季75k/100k、DOMA参议院84/85票、Cloud参数150/1024字符；任选一边不是解决冲突，也不能仅据另一段将该数字判为凭空编造。
- **对话用途与事实问答混淆。** FiQA的“能帮我吗”不需要外部来源来证明助手能回应；对德国经济多元化的认同也不应被portfolio材料拖成个人投资讲解。短答/拒答本身没有固定方向：Govt某条32B短答漏掉申请意图，但无来源的检测结果时长拒答合理。

也有必须保留的正例：本次两模型的Cloud附件10MB/请求11MB绑定正确限制表，没有复现旧7B的错引用；32B在若干许可、customer ID、Carthage和DOMA时间问题上保留了更多条件；两模型均拒绝从DOMA法律材料编婚礼仪式，或从剧情编演员现实关系。这些局部改进与新增错误同时存在，不能据代表案例宣布总体胜负。
