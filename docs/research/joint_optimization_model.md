# 联合目标与当前决策原理

ContextKV 面向有限 GPU/Host 下的动态证据多轮问答。研究对象是一段实际交互及其资源影响：保持必要证据、历史与回答质量，在共同模型和资源预算下减少完整响应时间。当前实现根据已提交历史和原生状态进行逐轮成本决策。下述完整成本是在线选择的近似目标，整体效果按[评价指标](../project_scope.md#研究目标与指标)中的回答质量、响应性能、服务能力、资源效率和工程可靠性判断。

## 目标与可行域

请求到达为 \(a_i\)，完整响应与持久提交中较晚时刻为 \(c_i\)。当前在线近似目标为最小化 \(\mathbb E[\sum_i(c_i-a_i)]\)，另报会话等权均值、尾延迟、失败、截断及质量维度。各指标按原单位分别报告。未完成任务保留在分母；P3 包含检索成本。

A 为当前问题构造 APPEND 与 REBUILD：两者共享必需证据、可引用 ID、输出预算和完整实际 QA。差别在于是否保留旧证据位置。证据版本冲突、缺失正文、历史失同步或超出窗口先排除，不让成本选择违反正确性合同。

## 当前选择

对可行候选 \(x\)，B 估计

\[
\widehat C(x)=T_{control}+\widehat T_{admission}(x)+\widehat T_{prepare}(x)
             +\widehat T_{forward}(x)+\widehat T_{decode}(x).
\]

forward/decode 复用真实阶段测量，输出长度只使用已完成历史。准备与等待依据原生缓存、工作量和容量观测；已包含在联合测量中的传输不再累加。`native_budget` 将原生容量预留与预计服务长度分开，最终调度仍由 SGLang 完成。等待项采用解析估计，异质队列的估计误差尚待实测。

只要成本不同，就选预计完整成本较低者。单臂误差不等于切换成本，故误差带仅用于诊断预测差值，不强制偏向追加或短输入。成本完全相同时，才按可用原生观测比较输入占用需求 \(n-D+I\)：连续 GPU 命中为 \(D\)，其中仍可淘汰、需要当前请求新增硬锁的部分为 \(I\)。已有软引用不是免费容量。观测含队列、Host 洞或在途传输时，采用共同逻辑输入长度作平局排序。没有支持域的候选采用明确简单策略。

C 将选中布局映射到业务 epoch。新答案持久提交后解除旧 epoch 软引用；它不提前提供可用空间，也不替代引擎的分配、淘汰与传输。这使 A 的文本取舍、B 的即时成本和 C 的版本生命周期在同一实际状态上协作。

## 追加什么时候有价值

稳定或高度重叠的证据、近期 GPU-ready 前缀、少量新增内容且不挤压并发准入时，APPEND 可以减少实际 Prefill。收益需要大于更长上下文的 Decode、控制和资源成本。证据频繁切换、旧材料持续累积、Host 恢复或容量等待占主导时，REBUILD 可能更好。

即使证据完全相同，Qwen3 的非思考模板也可能在历史 assistant 前导处改变 token。候选使用完整渲染的真实 IDs，由引擎报价给出实际命中边界。请求内分词复用仅在已确认的 AddedToken 边界进行，且与整段原生编码逐 token 对齐。

## 适用边界

逐轮决策以当前请求成本为目标，布局还会影响未来输入、回答长度与其他会话驻留。扩展决策可利用实际轨迹估计这些后续影响，并比较预期收益与额外计算成本。

资源积分按全局唯一槽位采样，共享祖先计一次。闭环负载下，动作会改变下一轮到达时刻、实际历史和排队过程；这种比较反映同一用户脚本的交互结果。机制归因结合相同输入的局部证据，整体结论以共同负载为准。

成熟依据包括 SGLang 原生准入与缓存机制、标准测量/插值、条件输出长度统计，以及成本感知缓存的大小与取回代价分析。[Landlord 作者论文](https://www.cs.ucr.edu/~neal/publication/Young02Online.pdf)可提供理论背景，但共享前缀、双层异步状态和变化的执行成本不满足其原假设，本实现不继承该竞争比。具体复用见[机制与研究依据](../research_contributions.md)，当前结果仅维护在[数据与评价](../data_and_evaluation.md)。
