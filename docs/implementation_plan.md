## 剩余瓶颈与投入原则

1. **质量与证据范围。** 当前 ContextKV 没有引用正文缺失的 ID，但有 1 条引用超出当前范围的旧证据；语义质量仍须结合完整来源判断。优先解决实际来源/条件错误，不以增加 judge 或训练作为默认办法。
2. **相对原生的净收益。** 控制成本已下降，但短回答时固定开销更显著；原生自身也能复用前缀。真实输出长度变化、旧材料干扰及冷启动长度先验仍影响选择。继续改进需指出具体根因与预期净收益，避免阈值搜索。
3. **结果范围。** 当前对照是开发诊断，不是独立冻结测试。正式论文级整体优胜需要明确质量资格与独立样本；无需因此重跑已完成的功能、标定或庞大矩阵。

训练、teacher、多阶段来源计划、更多模型评分工具、旧模型与重复实验不进入当前任务。额外机制只有在整体收益足以覆盖复杂度时才启用。阶段性交付包含可运行工程、真实正/负结果和明确边界，不等待所有开放研究问题全部解决。
