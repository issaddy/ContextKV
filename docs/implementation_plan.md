# 当前实现与交付状态

2026-10-26。主线是依赖外部资料、真实历史和动态证据的多轮文档与知识问答，在有限 GPU/Host 资源下协调回答质量、服务性能与资源效率。应用不限定行业；场景与指标见[项目范围](project_scope.md)，实际结果见[数据与评价](data_and_evaluation.md)。本文件是唯一的当前工作清单。

整体优化目标已启用：优先解决 A/B/C 的实际协同瓶颈，复用成熟机制，允许必要的组合、改进和替换；保持工程可运行、可维护，以完整任务效果判断价值。

## 当前可用工程

| 模块 | 已实现及协同 | 当前边界 |
|---|---|---|
| A：证据与上下文 | 多轮任务承接、条件切换、纠正与回访；版本/来源/依赖；完整实际 QA；共同 APPEND/REBUILD 证据和引用范围；当前检索优先级与缓存正文顺序分离 | last3 为已测快路径；无辅助模型的 conversational 增强可选，复杂指代可按需启用同一 Qwen3 服务 |
| B：成本选择 | 同批原生报价、实测 forward/decode、当前回答协议的长度估计、分动作控制耗时反馈；原生准入预算与服务长度分账 | 意图标签和证据零交集不强制重建；8B 成本表适用已测 H200 配置，32B 使用自身 scope，不套用 8B 测量 |
| C：生命周期 | epoch、软引用、CAS、attempt/outbox、成功提交后退役、响应丢失恢复、引擎重启处理 | 物理分配、锁、传输、淘汰复用 SGLang；退役 ACK 不等同于立即释放全部槽位 |
| 服务与交付 | CLI/HTTP 自动检索、多会话、幂等、实际历史/原文审计、关闭恢复、固定部署、wheel/sdist、同源原生/简单对照 | 生成 GPU0、检索 GPU1；线程环境、模型/索引/成本和运行身份显式记录 |

共同链路为：检索及派生意图 → 同一证据集合的两种上下文 → 原生报价和实际成本选择 → 生成 → 回答/意图/epoch 原子提交 → 旧引用退役。幂等重放与恢复复用已固定计划，不重复解析或检索。

## 本次实质改进

明确具名的任务补充现在复用已有 BGE 和 RRF：完整任务、当前条件对同一候选池评分，保留完整任务首位资料，再按融合排名补齐五段。它同时保留任务资料入口和当前条件偏好，不新增索引搜索、辅助生成、模型或配置开关。普通轮次沿用原流程；两种上下文消费相同的选择结果，B/C 合同不变。

保存的真实 50 段评分回放同时保留 Cloudant 的 schema 说明、排除 watsonx.data 建表材料。仅新增两次 Qwen3-8B 生成，使用原来的七轮实际 QA：APPEND 和 REBUILD 均解释无需预定义 schema，没有再混入另一产品的建表步骤。APPEND 保留旧正文仍能遵循本轮条件；REBUILD 的部分 API 示例不正确，作为剩余生成问题保留。具体依据与范围见[本次验证](data_and_evaluation.md#本次条件与任务证据联合选择)。

这一改动保留在可选多轮增强路径，尚不替换默认快配置。额外条件评分只在明确触发轮次执行，既有单轮测量为 50 对约 304 ms；应由任务收益覆盖这项成本，不能据两次生成推断整体提速。

## 已完成的精简与纠偏

- 字面任务承接省去一次自由改写；普通轮次、无模型和失败解析共用近期历史投影，直接复用最近已提交解释。
- 来源资格直接提取合格名称，移除构造后丢弃的完整诊断目录；额外说明字段不再使有效解析失败。
- 原生 JSON 编码器直接遍历 token 容器，固定成本插值结构启动时复用；解析 HTTP 等待与 BGE 模型锁分离。
- 去掉证据零交集禁止追加的规则、重复优先级注释和恒为 false 的笼统性能标记。
- 评价只使用当前任务要求及适用维度，分开报告未评估与不合格；历史污染批次不参与技术取舍。
- 当前清单按模块和结论合并，历史数字集中在评价文档；不增加逐轮纪要。

证据身份/版本、预算、提交一致性和失败恢复继续保留。这些支撑正常服务；没有收益的重复检查、计算和额外机制不作为交付条件。

## 剩余关键工作与投入顺序

1. **形成增强路径的整体收益判断。** 已有条件案例支持保留机制，下一步以预先声明的多轮任务子集确认适用范围和完整成本；先使用已有原文、回答和调用轨迹，只有影响配置取舍的缺口才新增真实验证。
2. **把优化落在共同瓶颈。** 优先处理任务证据遗漏、错误条件沿用、检索/控制重复工作；生成示例的局部错误按来源和影响归因，不据此增加通用后处理、训练或多轮评审链。
3. **完成阶段交付与结论。** 同步部署、包、源码身份和证据；以目标任务质量、完整响应、时延达标服务与单位完成轮次 KV 占用判断。正式论文级广泛优胜需要相应独立样本，现有工程和已观测收益不因此被否定。

方法和贡献不预先收窄；新增机制需要解决实际瓶颈。阶段交付包含可用工程、正负结果与适用边界，不等待解决基座模型全部错误，也不机械扩展实验矩阵。
