## 当前工作顺序

1. **保留已打通的工程交付。** 现有源码、Qwen3 成本配置和 A/B/C 已在容器中联合执行；保持源码清单、产物及使用入口一致，不重新标定已覆盖范围。
2. **修正已定位的选择问题。** 默认固定轮数冷却已移除；继续处理误差门槛单向偏向追加、长输入增加并发工作集的问题。先复用提交前报价和实际轨迹，分析原生准入与上下文组织的交互，再决定最小实现改动。成熟方法和原生方案均可采用，不为保留既定机制而增加复杂度。
3. **补足联合效果判断。** 优先审阅已有完整答案与失败/截断记录。实际机制改动后，才针对关键不确定性做必要的闭环对照；最终关键结论再冻结独立验证。同模型、材料及资源预算，比较原生前缀/会话/HiCache及强简单策略，联合报告质量、完整响应、吞吐、资源和失败。

每项工作完成后更新本表与必要结果，不新增另一份阶段计划。新发现先判断是否阻断上述工作或直接改善其效果；有价值的方法仍可复用、优化或替换，但无关扩展留在参考材料中，不自动进入执行队列。
