## 当前工作顺序

1. **交付现有主线。** 核对当前源码、共享 Qwen3 配置、检索入口、A/B/C 与导出接线；部署尚未同步的修复，保留实际部署清单。已有正确性结果直接复用。
2. **补 B 的必要成本支持，并打通 C 的效果观测。** 先检查已有数据与原生机制；只对影响决策的成本空白补采。共同负载包含合理的证据复用、变化、回访和资源竞争，不能以回退结果评价未启用算法。
3. **完成共同负载验收并交付。** 同模型、材料及资源预算，对照原生前缀/会话/HiCache与强简单策略。联合报告质量、完整响应时间、吞吐、资源和失败；只为关键归因补必要消融或独立验证。

每项工作完成后更新本表与必要结果，不新增另一份阶段计划。新发现先判断是否阻断上述工作或直接改善其效果；有价值的方法仍可复用、优化或替换，但无关扩展留在参考材料中，不自动进入执行队列。
