# 共享编码与原生 KV 协同重构

固定 Qwen3-32B。查询、证据、文档计算和缓存执行以同一版代码、辅助权重及文档索引交付。

## 主调用链

问题与已提交历史 → Qwen 共享任务/查询编码 → 合法范围混合召回 → Jina 共享证据编码 → 集合选择与结构化计算 → 价值停止 → 一次请求编译与提交 → SGLang 精确或 InfoFlow 执行 → 答案与来源提交。

- 查询侧采用 Qwen3-Embedding-0.6B，RCEM 会话表示对齐与任务关系头共用一次前向。文档向量由冻结的 Qwen 文档编码器重建。
- Jina-reranker-v3.5 的 token 与段落表示共同服务重排、字段/时期/实体/来源绑定、集合效用和停止判断。集合头使用固定生成模型的真实答案效用。
- 文档索引保存原文跨度、表格行列、单元格与版本对应关系。先投影字段，再筛选、连接和聚合；CPU 运算保留来源与总体覆盖。
- 停止头预测 STOP/CONTINUE 的终端质量、完整剩余成本及响应尾延迟。训练使用逐状态实际 STOP 答案与完整扩展轨迹的 Q(lambda) 回报。全量统计由合法总体覆盖和运算完成决定可否回答。
- 实际请求携带原文块地址和后续需求。SGLang 管理独立块 KV、全局位置、注意力选择的 token 重算、请求私有覆盖及同套 GPU/Host 页。精确路径和非前缀路径的成本包括冷建、打分、迁移和重算。
- 辅助输入就绪后合批；prefill 和重算增量调度。失败请求不写入语义历史，后续轮次使用实际已提交历史。

## 替换范围

替换在线主模型任务解释、独立查询改写/支持编码器、逐 Need 重排、排名覆盖选材、全事实生成后再次选择、动作/布局枚举、ContextPilot 多排列搜索和外置缓存租约。保留来源地址、Need 依赖、确定性运算及公开 benchmark 评分能力。

## 训练与评价

结构头使用任务、字段和来源标签；集合/停止头使用真实答案质量和执行成本。辅助骨干与任务头共享表示，Qwen3-32B 权重保持固定。训练记录只保存必要标签、来源地址、共享特征和结果费用。

先完成主链与引擎接线，再训练并运行少量端到端问答。逐 benchmark 比较普通文档问答、ContextKV 和 LlamaIndex，报告最终质量、完成率、完整响应 P95 及 GPU/Host 累计占用。缓存解释仅保留命中、回载、重算和必要的控制开销。

## 方法依据

[RCEM](https://arxiv.org/abs/2606.01697) 提供会话到改写查询的表示对齐；任务关系头由项目实现。
[Jina-reranker-v3.5](https://huggingface.co/jinaai/jina-reranker-v3.5) 提供列表编码与重排；字段/来源和集合头共享其隐藏表示。
[OptiSet](https://arxiv.org/abs/2601.05027) 提供集合生成效用监督思路。
[TableRAG](https://aclanthology.org/2025.emnlp-main.710/) 与 [VersionRAG](https://arxiv.org/abs/2510.08109) 支持结构化文档执行和版本变化定位。
[Stop-RAG](https://arxiv.org/abs/2510.14337) 提供完整轨迹的停止价值学习。
[InfoFlow KV](https://arxiv.org/html/2603.05353v3) 提供独立块 KV、全局位置与查询注意力选择性重算；SGLang 的页管理、私有覆盖和统一需求调度由项目集成。

当前进度：共享编码、结构化计算与 SGLang 执行并行重构中；尚未完成本版训练和 GPU 验收。
