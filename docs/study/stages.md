# 接续顺序

当前机制和实施任务统一维护在 [review_20261103.md](review_20261103.md)，已完成实验统一维护在 [final_report.md](final_report.md)。原阶段记录由 Git 历史保留。

| 顺序 | 交付 |
|---|---|
| 1 | 使用修正后的官方指标重评原始答案；固定完整 cohort 与当前可行参照 |
| 2 | R0 重放任务撤销、缺口补齐、长文计数/求和、多跳与有限归约；比较逐步骤成本 |
| 3 | 生成可见输入一致的新 reader 目标；重训并完成 planner × reader 四格和自身 P3 |
| 4 | 以当前 reader 重新采集动作收益，比较固定计划、收益停止和两步滚动计划 |
| 5 | 固定输入做 native/不同 TTL 的保留机会实验，再学习相对当前保护集合的价值 |
| 6 | 在相同质量、完整响应与物理容量条件下完成 B × C 联合和公开持出评价 |

实现、数据、模型、指标和成本的接续条件见 [reader_policy_readiness.md](reader_policy_readiness.md)；实际命令见 [final_runbook.md](final_runbook.md)。
